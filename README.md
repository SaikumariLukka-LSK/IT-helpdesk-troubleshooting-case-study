# IT Help Desk Troubleshooting Case Study

I completed this project as part of my Computer Support Specialist training with Correlation One. I worked through a simulated Tier 1 support ticket involving a slow Windows 10 laptop, frequent Wi-Fi drops, and unexpected pop-ups.

I wrote questions to clarify the issue, identified three possible causes, and chose Task Manager as my first check. It would let me review CPU, memory and disk usage without restarting the laptop while the employee had unsaved work.

I explained why the unexpected pop-ups warranted escalation to Tier 2, what I would include in the handover, and how I would verify that the issues were resolved before closing the ticket.

**Skills practised:** Windows troubleshooting, Wi-Fi triage, security awareness, ticket escalation and documentation.
